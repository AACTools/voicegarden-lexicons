# Training code moved

The ML training pipeline (ByT5 G2P/P2G + fuzzy phoneme decoder:
train/export/quantize/eval, corpus generators, corruptor, calibration)
now lives in a private companion repo: `willwade/floravox-training`.

This repo remains the DATA project: audited lexicon bundles, convention
folds, licensing gates, releases. Historical copies of the training
scripts remain in this repo's git history up to 2026-11-18.
